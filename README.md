# 🎬 MovieCity — Landing Page de Filmes

## 📌 Sobre o Projeto

O MovieCity é uma landing page desenvolvida como atividade prática do curso de TI, com o objetivo de apresentar uma interface voltada para filmes e entretenimento. O projeto possui um design moderno, com imagens de filmes, menu de navegação e uma área principal de apresentação.

A atividade foi desenvolvida para praticar conceitos de desenvolvimento front-end, organização de componentes, estilização e criação de páginas responsivas.

## ✨ Funcionalidades

- Cabeçalho com o nome MovieCity.
- Menu de navegação com as opções Filmes, Categoria, Sobre e Contato.
- Botão de Login.
- Área principal com apresentação do site.
- Cards com imagens de filmes.
- Efeitos visuais ao passar o cursor sobre os cards.
- Layout responsivo para diferentes tamanhos de tela.
- Menu adaptado para dispositivos móveis.

## 🛠️ Tecnologias Utilizadas

- **React:** criação da interface por meio de componentes.
- **Vite:** ferramenta utilizada para executar o projeto.
- **JavaScript:** desenvolvimento da lógica da aplicação.
- **CSS:** estilização, organização dos elementos e responsividade.
- **ESLint:** ferramenta para auxiliar na identificação de possíveis problemas no código.

## ▶️ Como Executar o Projeto

Para executar o projeto localmente, é necessário ter o Node.js instalado.

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o terminal integrado.
3. Execute o comando para instalar as dependências:

   ```bash
   npm install
   ```

4. Inicie o projeto com o comando:

   ```bash
   npm run dev
   ```

5. Acesse no navegador o endereço informado pelo Vite no terminal.

## 📱 Responsividade

O projeto utiliza recursos do CSS para adaptar a interface a diferentes tamanhos de tela, permitindo uma melhor visualização em computadores, tablets e celulares.

Em telas menores, os elementos são reorganizados para facilitar a navegação e melhorar a experiência do usuário.

## 🎯 Objetivo da Atividade

O objetivo desta atividade é desenvolver uma landing page utilizando React, praticando a criação de componentes, a organização do código, a aplicação de estilos CSS e a construção de uma interface responsiva.
